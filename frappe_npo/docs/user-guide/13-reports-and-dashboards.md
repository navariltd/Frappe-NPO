## 13.2 What each report is for

| Report | The question it answers |
| --- | --- |
| **Donation** | What came in during the period, pledged vs received vs distributed. |
| **Donation Payments** | Which payments make up that total — reconcile with the bank. |
| **Donor Contribution** | Where a donor's money went, by recipient and project. |
| **Donation Allocation** | What is allocated and what is still sitting unallocated. |
| **Donation Budget Allocation** | How much of each budget came from donations. |
| **Expiring Memberships** | Whose membership ends in a chosen month — the renewal list. |
| **Beneficiary** | Who we serve, cut by programme, donor, type, status, area and dates. |
| **My Cases** | A worker's own worklist, by status. |
| **Daily Visit Update** | Field visits by worker and date. |

**Working with any report:** set the filters, star it to save them for next time, export
to Excel or CSV for a meeting, and switch to chart or grouped view where you need a
picture rather than a list. Reports respect roles — an empty report usually means you are
not permitted to see the underlying documents.

## 13.3 Dashboards

The Beneficiaries workspace carries the numbers a manager needs daily:

| Element | What it tells you |
| --- | --- |
| **Cases per week** | Throughput of the field team — a falling line with a growing open count means cases are not being closed. |
| **Rescues per week** | Field activity and emerging hotspots. |
| **Entitlement Requests per week** | How much government paperwork is actually being completed. |
| **Total Beneficiaries** | How many people are on file. |
| **Total Rescues** | Cumulative rescues — the headline for most reports. |
| **Closed Cases** | The "done" figure for management reviews. |

Click a data point to drill into the documents behind it. Build your own dashboard when
you need a different cut — cases by type, beneficiaries by zone, spend by project.

## 13.4 A monthly reporting routine

1. **First working day** — run the donation and donation payment reports for last month;
   confirm that what was distributed equals what was allocated.
2. **Memberships** — run Expiring Memberships for next month and send the renewal list to
   the membership team.
3. **Programme** — run the beneficiary report (active only) and My Cases per worker; flag
   cases sitting in follow-up too long.
4. **Disbursements** — look for submitted orders whose beneficiaries still have no payment
   or stock entry, and chase the verification requests still open.
5. **Funders** — update each partner's impact record and export the donor contribution
   report as the annexure.
